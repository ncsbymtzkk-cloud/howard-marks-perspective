# Agent 5: 关键决策记录

## 标志性决策案例

### 决策1: 2008年金融危机——史上最大胆的买入
- **背景**：雷曼兄弟破产，全球金融市场崩盘
- **决策**：创建110亿美元困境债储备金，9月18日至年底每周买入约6.5亿美元
- **总投入**：75亿美元（约占当时管理规模的30%）
- **风险**：如果金融系统完全崩溃，投入的资金可能全部损失
- **结果**：债务反弹，Oaktree 投资者获利约60亿美元，Marks 个人获利约15亿美元
- **决策逻辑**（Marks 原话）："如果世界末日来了，我们做什么都无所谓。如果世界没末日而我们没投资，我们就没做好工作"
- **关键教训**：极端恐惧时刻往往是最好的买入时机——前提是你做好了充分的研究

### 决策2: 2007年——在狂热中撤退
- **背景**：2005-2007年信贷市场极度繁荣，利差收窄至历史低位
- **决策**：大幅降低投资组合风险，减持高风险资产，建立防御姿态
- **具体行动**：出售大量高收益债，持有更多现金和国债
- **当时市场反应**：被同行嘲笑为"过于谨慎"
- **结果**：2008年危机来临时，Oaktree 的损失远小于同行
- **决策逻辑**："当大家都在赚钱而我感到不安时，就是该撤退的时候"

### 决策3: 2012-2019年——"低回报世界"中坚持纪律
- **背景**：利率降至零，优质资产极度稀缺
- **决策**：主动缩减多只基金规模，停止接受新资金，而不是降低投资标准
- **影响**：短期内损失大量管理费收入
- **长期结果**：保持了优秀的投资业绩记录
- **决策逻辑**："我们宁愿小而精，也不要大而差"

### 决策4: 2020年3月——疫情崩盘中逆向加仓
- **背景**：新冠疫情导致全球市场在数周内暴跌30%+
- **决策**：在市场最恐慌的时刻开始买入
- **行动**：发表"Nobody Knows"备忘录，承认不确定性，然后开始部署资金
- **关键细节**：同时保持了足够的现金储备以防情况进一步恶化
- **决策逻辑**："当不确定性最大时，机会也最大。前提是你能承受最坏的结果"

### 决策5: 2021年——重新定义"价值投资"
- **背景**：传统价值投资策略连续多年跑输成长股
- **决策**：在备忘录中公开宣布——"价值投资不等于低估值投资"
- **影响**：引发投资界广泛讨论，一些传统价值投资者表示反对
- **决策逻辑**："Albert Einstein 据说说过——'不是所有重要的东西都能被计算，也不是所有能被计算的东西都重要。'不能被精确预测的东西并不意味着它不是真实的"

### 决策6: 持续13年的定期投资
- **时间跨度**：2009-2021年
- **决策**：虽然经历了"失落的13年"（Oaktree AUM增长缓慢），但始终坚持原有投资哲学，没有跟风追逐热门策略
- **考验**：来自 LP（有限合伙人）的压力、来自同行的嘲笑、来自媒体的质疑
- **结果**：13年后的2022年开始，这些年的纪律积累带来了丰厚回报

## 决策模式总结

| 决策特征 | 出现频率 | 说明 |
|---------|---------|------|
| 逆向操作 | 高 | 在市场极度乐观时谨慎，在极度悲观时买入 |
| 宁可错过不做错 | 高 | 多次主动缩减规模或停止投资 |
| 承认不确定性 | 极高 | 几乎没有"确定"的决策，总是保留余地 |
| 耐心 | 极高 | 愿意等待数月甚至数年让 thesis 验证 |
| 纪律优先于直觉 | 中 | 严格遵守投资流程，即使短期痛苦 |
