# Agent 6: 时间线

## 霍华德·马克思完整时间线

| 时间 | 事件 | 影响 |
|------|------|------|
| 1946年 | 出生于美国纽约 | — |
| 1963-1967 | 宾夕法尼亚大学沃顿商学院本科 | 金融专业，奠定量化分析基础 |
| 1967-1970 | 芝加哥大学布斯商学院 MBA | 接触到有效市场假说（EMH），成为其一生的"对手" |
| 1969年 | 加入花旗银行担任股票研究员 | 开始16年的机构投资生涯 |
| 1978年 | 升任花旗 VP 和高级投资组合经理 | 管理可转换证券和高收益债组合 |
| 1978年 | 与 Michael Milken 的关键会面 | 认识到高收益债的逻辑——"只要能活下来就只有一条路：向上" |
| 1978年 | 花旗成为纽约市财政危机的主要应对者 | 第一次经历真正的市场危机 |
| 1985年 | 离开花旗，加入 TCW 集团 | 成为 TCW 高收益债和可转换证券业务负责人 |
| 1985年 | 与 Sheldon Stone 在 TCW 共事 | 开始建立长期合作伙伴关系 |
| 1987年 | 与 Bruce Karsh 合作建立 TCW 特殊信贷基金 | 进入困境债务投资领域 |
| 1990年 | 撰写第一份备忘录《通往业绩之路》 | 提出"避免输家"哲学——Oaktree 的 DNA 形成 |
| 1995年1月 | 与5位合伙人共同创立 Oaktree Capital Management | 从零开始，初始7个策略 |
| 1995年 | Oaktree 开始运营 | 初期管理约70亿美元资产 |
| 1996年 | Oaktree 首次客户大会 | 建立与机构投资者的关系 |
| 1998年 | AUM 突破100亿美元 | 开始全球扩张 |
| 1998年 | 设立新加坡办公室 | 第一次海外扩张 |
| 1999年 | 设立伦敦办公室 | 进入欧洲市场 |
| 2001年 | 推出 mezzanine 投资策略 | 进一步多元化产品 |
| 2004年 | TCW 经历内部动荡 | 间接促使 Marks 思考机构治理和文化 |
| 2006年2月 | 发表里程碑式备忘录《风险》 | 首次系统阐述"风险≠波动"理论 |
| 2007年 | 预判信贷泡沫，主动降低风险 | 在市场狂热中逆向撤退 |
| 2007-2008年 | 创建110亿美元困境债储备金 | 为金融危机中的历史性买入做准备 |
| 2008年9-12月 | 金融市场崩盘期间大举买入 | 投入75亿美元买困境债，最终获利约60亿美元 |
| 2009-2019年 | "失落的13年"（相对低回报） | 坚持纪律，未追逐热门策略 |
| 2011年 | 出版《最重要的事》 | 将投资哲学系统化出版 |
| 2012年2月 | 发表"Investing in a Low Return World" | 标志性地定义了新的市场环境——低利率时代的投资策略调整 |
| 2018年10月 | 出版《掌控市场周期》 | 补充钟摆理论的框架 |
| 2018年10月 | 市场大跌期间坚持买入 | 再次实践"钟摆底部买入"的哲学 |
| 2020年1月 | 发表《Nobody Knows》 | 承认极端不确定性，但随即开始大举部署 |
| 2020年3-12月 | 疫情崩盘中持续买入 | 以每周数亿美元的速度积累 |
| 2021年5月 | 发表"从价值投资角度看"备忘录 | 重新定义"价值"——成长股也可以是价值投资 |
| 2021年 | Oaktree AUM 达到约1550亿美元 | 达到历史最大规模 |
| 2022年 | 利率上升，市场巨变 | 开始新的投资周期 |
| 2024年 | 获得行业终身成就奖 | 职业生涯的荣誉认可 |
| 2025年 | 持续发表备忘录讨论AI、贸易等议题 | 80岁高龄仍活跃在投资思考的第一线 |

## 最新12个月动态（2025-2026）
- 持续撰写关于私人信贷市场的备忘录，承认该领域竞争加剧但坚持 Oaktree 的选择
- 讨论 AI 对投资行业的影响——认为 AI 可以辅助分析但无法替代人类的判断力
- 2026年3月发表《Gimme Credit》，认为信用债仍然具有吸引力
- 已近80岁高龄，仍保持每年6-8篇备忘录的频率
